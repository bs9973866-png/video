# Что, если бы интернета никогда не было? — Remotion

Стартовый аниматик научно-популярного ролика на русском языке.

## Запуск

```bash
npm install
npm run start
```

Открой композицию **NoInternet** в Remotion Studio.

## Рендер

```bash
npm run build
```

Готовый файл появится в `out/no-internet.mp4`.

## Что уже есть

- Композиция 1920×1080, 30 FPS.
- 10 иллюстрированных сцен с движением, плавным появлением и затемнением.
- Русский текст на экране.
- Отдельный файл субтитров SRT.
- Полный черновик сценария и монтажные заметки в `SCRIPT.md`.

## Что нужно добавить перед финальным выпуском

- Запись или синтез дикторской дорожки.
- Музыкальную дорожку и звуковые эффекты.
- Синхронизацию длительности сцен с полным текстом диктора и субтитрами.

Аудио-файлы, если они будут подготовлены, размещаются в `public/audio/`.

# Последнее сообщение — детальная 2D-анимация

Трёхминутная история Remotion: 36 отдельных сцен со сменой каждые 5 секунд, выразительные персонажи с артикуляцией рук и ног, циклом шага, наклоном корпуса, движением головы и мимикой. Фоны — отдельные локации с предметами, зданиями, улицами, транспортом и атмосферными деталями.

Озвучка: мужская русская нейросетевая модель Piper **Dmitri**, с более низким тембром, мягким замедлением и компрессией.

## Сборка

```bash
npm install
pip install piper-tts
sudo apt-get install ffmpeg
python scripts/generate_voice.py
npx remotion browser ensure
npm run render
```

Готовое видео: `out/last-message.mp4`. GitHub Actions собирает MP4 при обновлении main. После изменений длительность дорожки проверяется через ffprobe.
